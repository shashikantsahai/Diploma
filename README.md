# Diploma AI Mentor — Mobile v1

Flutter Android/iOS-ready mobile-first prototype.

Included:
- Student home with previous activity
- Daily / weekly / monthly improvement
- Daily 10 practice
- Better explanation entry point
- AI Mentor UI
- Skill path and next-skill recommendation
- Mobile bottom navigation

Run:
flutter pub get
flutter run

Build Android:
flutter build apk --release

Production backend still required for:
LLM question generation, RAG, authentication, server-side authorization,
PostgreSQL Row-Level Security, student data isolation, admin dashboard,
payments, secure code execution, ML models and analytics.
